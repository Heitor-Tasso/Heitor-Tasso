## 👨‍💻 Sobre mim

Sou apaixonado por inovação, arquitetura de software e automação de processos. Com formação técnica em Eletrônica e Eletrotécnica e graduando em Análise e Desenvolvimento de Sistemas (FATEC), uno o conhecimento de hardware e software para criar sistemas eficientes, escaláveis e seguros.

Atualmente, sou **CTO na SoTahTech**, onde lidero a arquitetura de infraestrutura (Docker Swarm, Dokploy, Traefik) e o desenvolvimento de soluções ponta a ponta. Também atuo como **Analista de Automações e Integrações na Asimov Academy**, orquestrando fluxos complexos e automações.

## 💼 Portfólio e Projetos

A maior parte do meu trabalho recente está hospedada na [organização da SoTahTech](https://github.com/SoTahTech-Solucoes-Tecnologicas-LTDA) ou em repositórios privados, englobando soluções B2B, SaaS e infraestrutura interna.

### 🏢 Produtos & Infraestrutura (SoTahTech)
* **Arquitetura Swarm & Dokploy:** Gerenciamento de múltiplos ambientes (Dev, Stage, Prod) utilizando Docker Swarm, Traefik para roteamento, Infisical para gestão de segredos e integração contínua (CI/CD) via repositórios privados.
* **TopTrendsAI:** Plataforma de análise impulsionada por IA, focada em entregar insights acionáveis (Fase de testes/Privado).
* **Calculadora de Aposentadoria:** SaaS focado em planejamento financeiro com cálculos complexos de previdência.
* **Gestão Financeira & RIV:** Sistemas web modulares voltados para controle e automação financeira corporativa.
* **DeepMirror-WebSites:** Ferramenta desenvolvida em Python para Runtime Network Recording, capturando sites de alta fidelidade e experiências complexas em tempo de execução.

### 🌍 Open Source & Destaques Pessoais
* [**KivyGo**](https://github.com/Heitor-Tasso/kivygo) & [**KivyMaker**](https://github.com/Heitor-Tasso/KivyMaker): Criação de bibliotecas, widgets focados em design e uma IDE visual (estilo Android Studio) para simplificar o desenvolvimento de aplicações Python usando o framework Kivy.
* [**Irrigação Automatizada com ESP8266**](https://github.com/Heitor-Tasso/ESP8266-AutomatedIrrigation): Projeto de TCC unindo hardware embarcado (C/C++) e painel web para gestão de sensores e atuadores.
* [**Spotify Clone**](https://github.com/Heitor-Tasso/SpotifyClone): Recriação da interface do Spotify utilizando Python e Kivy para estudos de UI/UX em aplicações desktop/mobile.
